# 管理项目测试报告

测试环境：Windows、本机 Node.js 24.21.0、SQLite、Qwen2.5 1.5B 和 llama.cpp。

- 基准数据 15,184 条：唯一编号、关联、票务和退款金额、项目流水、薪资、积分余额校验通过。
- 业务测试 11 个场景：角色校验、审批、预算占用、超预算回滚、版本冲突、验收前付款拒绝、幂等回执、幂等付款、证据保存与重启后持久化通过。
- 真实 HTTP 闭环 22 次请求：预算 50,000 元、采购 3,200 元、验收后登记付款，可用预算 46,800 元，待履约占用归零。重复同一付款请求没有新增流水。
- 本地模型项目资料分析耗时 3672 ms，来源标签存在性校验通过。该校验不证明模型每句话语义正确。
- DOM 集成测试覆盖服务端登录、立项保存、完整数据和分页，无脚本异常。

证据：evidence/business-e2e.json。业务重启与回执幂等由隔离数据库单元测试覆盖；本轮未在真实 Render 环境中部署或做在线重启验收。

未完成完整浏览器视觉验收；当前已做 DOM 和接口验证。没有真实银行付款或真实组织 SSO 测试。

Render 配置已通过官方 JSON Schema 结构校验，两个项目各自独立服务；默认免费配置不挂载磁盘，重启后的数据保留不属于云端验收项。SQLite 在线备份已生成并通过 PRAGMA integrity_check；该结果不代替真实 Render 部署和重启验收。
