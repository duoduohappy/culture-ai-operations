# 管理项目面试演示

建议用五到八分钟展示一条完整业务链，而不是逐页介绍按钮。

1. 打开默认采购经营闭环页，以 applicant 登录，创建一个 50,000 元预算的演出项目并提交。
2. 退出后用 approver 登录，批准立项，说明申请人无法批准自己的申请。
3. applicant 创建关联采购，金额 3,200 元，提交；approver 审核，查看预算可用额降为 46,800 元。
4. buyer 下单并保存一份报价资料；warehouse 验收；finance 登记付款。
5. 查看验收回执、财务流水、预算占用归零、实际支出增加和审计记录。
6. 用服务端项目资料分析生成带来源的建议，打开原始资料核验。说明 AI 无权审批或付款。
7. 查看测试报告中的超预算、重复付款、过期版本和服务重启用例。

原有七模块和大量关联数据在总览与业务数据页；这些样本用于展示业务理解，不把旧浏览器模拟操作冒充服务端写库。

可写入简历的事实：独立实现文娱项目采购预算闭环，使用 SQLite 事务、角色权限、幂等和版本控制，集成本地大模型与资料引用校验。不要声称已替真实集团上线、节省了未经测量的人力或支持未测试的并发量。
