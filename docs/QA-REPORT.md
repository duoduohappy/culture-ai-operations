# 本轮回归测试报告

测试日期：2026-11-20。环境：本机 Windows、Node.js 24.21.0。

## 已验证

- 原有模块测试、15,184 条演示数据校验、11 组业务场景通过。
- 新增 5 组回归：金额类型、模型异常结构、缺失或不存在的来源、来源映射与去重。
- 新增 16 项 HTTP 检查：无效请求、体积限制、跨域与 Host 校验、视频分段读取和健康恢复。
- 免费 Render 环境本机模拟 11 次 HTTP 检查通过：安全登录、模型未配置、临时数据提示、新实例恢复完整演示数据。
- DOM 检查通过：加载失败可重试，恢复后清理错误，用户输入作为文本显示。
- 真实本地模型及 SQLite 闭环：22 次 HTTP 请求，立项→审批→采购→下单→验收→付款登记，可用预算 46,800 元；重复付款不重复记账。模型分析 3,672 ms，结构与引用标签校验通过。

## 已修复

请求体格式异常处理、金额类型校验、模型异常结构导致的接口错误、未知接口状态码、静态视频 Range 支持，以及加载失败后的重试与错误清理。

## 如何复现与边界

安装 Node.js 24 后执行 `npm ci`、`npm run test:all`。该命令无需模型或 OBS，使用隔离临时数据库。真实依赖验证另执行 `npm run test:e2e`。

未在真实 Render 实例验收；DOM 检查不代替完整浏览器视觉验收。未验证实体舞台设备、银行接口或生产负载。模型来源标签通过不等于每句话语义正确。免费实例冷启动恢复测试数据属于约定行为。
